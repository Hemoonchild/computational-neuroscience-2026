# Computational Neuroscience — 2026
Neuromatch-based local course

Documenting my path into computational neuroscience: two weeks of self-directed
prep, a 3-week Neuromatch-based Computational Neuroscience course (local Iran
cohort), and whatever comes after.

Covers scientific Python (numpy, scipy, matplotlib, pandas, scikit-learn) and
core math prerequisites (linear algebra, calculus/ODEs, probability), building
toward being ready to collaborate with other researchers once the course ends.
